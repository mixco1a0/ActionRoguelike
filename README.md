# Unreal Engine 5 Action Roguelike Game (Tom Looman Course Journey)

A project-based repository tracking progress through Tom Looman's [Professional Game Development in C++ and Unreal Engine](https://courses.tomlooman.com/p/unrealengine-cpp) course, featuring custom C++ framework, AI, and multiplayer systems.

## 🛠️ Development Environment
- **Unreal Engine Version:** `5.8`
- **Development Model:** C++ Core with Blueprint Extensions
- **IDE:** Microsoft Visual Studio 2026

## 📚 Course Curriculum & Roadmap Tracker

### Phase 1: Gameplay & Core Systems (Lectures 2-9)
- [ ] Collision traces & interfaces.
- [ ] Exposing C++ to Blueprints & debugging.
- [ ] UMG UI & dynamic materials.

### Phase 2: AI & Advanced Systems (Lectures 10-18)
- [ ] Behavior Trees & EQS (Environment Query System).
- [ ] Custom Action System with `GameplayTags`.

### Phase 3: Networking & Polish (Lectures 19-28)
- [ ] Client-Server replication & RPCs.
- [ ] Save/Load system.
- [ ] Performance profiling & Async Loading.
